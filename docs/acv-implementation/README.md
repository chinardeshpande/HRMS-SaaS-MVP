## Execution Sequence

1. Control room and gap register.
2. Tenant branding and organization settings hardening.
3. Tenant SMTP and outbound communication logging.
4. Company document vault.
5. Compensation hardening.
6. Audit and governance expansion.
7. ACV dashboards and UAT evidence.
8. Later Zoho Cliq and WorkDrive integration.

## Scope Rule

This implementation must keep payroll processing and recruitment/ATS out of scope. AuroraHR can track HR data, documents, salary structures, payslips, and imported salary outputs, but it must not become a payroll computation or statutory filing engine in this phase.
